# 应用需求:随身工具箱

本分支把设备做成一个 12 合 1 的工具箱。所有界面为中文自绘界面(不沿用基线测试菜单)。
本文记录已实现的行为与验收状态;硬件约束见
[硬件指南](../hardware-design/AI_HARDWARE_DEVELOPMENT_GUIDE.zh_CN.md)。

## 全局约定

- 按键(物理排布从上到下):上 ▲、下 ▼、确定。
- ▲▼ 单击:移动 / 调整;确定 单击:主操作;**长按 ▲:返回上一级**;长按确定、长按 ▼、双击由各应用定义,
  底部提示栏显示当前可用操作(放不下时从末尾省略)。
- 息屏时第一次按键只点亮屏幕;蓝牙遥控例外(息屏时按键照常发送)。
- 状态栏:时间、后台计时胶囊(番茄钟/倒计时剩余时间)、Wi-Fi / 蓝牙图标、电量。
- 设备上的电源键是独立硬件开关机键,没有接到主控,固件无法感知短按,因此不能用它息屏。

## 工具

| 工具 | 主要功能 |
| --- | --- |
| 番茄钟 | 环形进度、长休息(每 N 个)、跳过、自动开始、未确认每 30 秒提醒、本周统计;后台计时 |
| 时钟天气 | 大号时间、实况与 4 天 / 逐小时预报、床头钟模式 |
| 语音助手 | 按住确定说话;使用方式可选 自动 / 只用 Mac 中转 / 只用云端直连(识别 → 对话 → 朗读) |
| 蓝牙遥控 | 编程助手(Vibe Coding)、翻页笔、媒体、拍照;设备作为蓝牙键盘 |
| 声音工具 | 频谱与分贝计、调音器、节拍器 |
| 设备互联 | ESP-NOW 点对点:对讲、快捷消息、呼叫、一起专注 |
| 智能家居 / 信息看板 | 经服务器或直连 Home Assistant;看板无服务器时显示本机卡片 |
| 无线分析、计时器、随机、设置 | 信道占用、秒表 / 倒计时、骰子 / 吃什么、配网与系统信息 |

### 蓝牙遥控 · 编程助手

| 键 | 单击 | 长按 | 双击 |
| --- | --- | --- | --- |
| ▲ | ↑ | 返回模式列表 | ↓(▼ 为语音键时)或 Shift+Tab |
| ▼(语音键) | 按下即按下所选键,松开即松开 | 同左 | 同左 |
| 确定 | 回车 | Esc 打断 | 快捷指令列表 |

- 模式列表里用选项页选择并保存:▼ 的用途(语音键 / 向下 ↓)和语音键对应的电脑按键
  (Fn、左右 Control、左右 Command、左右 Option)。
- Fn 使用 Apple 私有报告;若该报告表导致 HID 初始化失败,自动退回基础报告表,界面提示改用 Command。
- ESP32-C3 只有 BLE,没有经典蓝牙耳机协议,设备不能作为电脑的蓝牙麦克风。

## 联网与服务器

- 开机若已配网,连一次 Wi-Fi 对时;等时间对好**且**第一次服务器发现完成后才关闭射频(最多 60 秒)。
- 服务器发现:设备向 255.255.255.255 与本网段广播地址发 UDP 8788 询问,并监听服务器每 3 秒发到
  UDP 8789 的主动广播;成功后用 HTTP 8787 配对取令牌。结果显示在 设置 › 关于本机 的"发现"一行。
- 找不到服务器时自动直连:天气(城市名查经纬度 / 手填经纬度 / 按 IP 定位 → Open-Meteo)、
  看板(本机卡片)、家居(局域网 Home Assistant)、语音助手(兼容 OpenAI 的云端,默认硅基流动)。
- 云端直连语音:对话和语音(识别、朗读)各有一组接口地址和密钥。语音接口留空表示同对话;语音密钥留空时只有两组接口相同才沿用对话密钥。配置页预设:DeepSeek 对话 + 硅基流动语音、硅基流动全包、OpenAI 全包(朗读按 24 kHz 重采样)、自定义。换接口地址而没填新密钥时清除旧密钥。
- 直连识别先建好 HTTPS 连接再开麦,开麦时响提示音;连接期间显示"连接中"。
- 出错时屏幕显示哪一步、为什么,例如"识别:密钥无效""对话:余额不足""朗读:网络不通";朗读失败时文字回复照常显示。中转模式下由中转在 `error` / `tts_error` 字段里给出同样的提示。
- 配置网页:手机连上设备热点自动弹出;状态卡、附近网络列表、天气位置(内置城市经纬度)、语音助手密钥与模型、
  家庭助手、服务器地址;保存后实时显示连接结果。网络名称留空只保存其他设置。

## 已知限制与安全

- API 密钥与 Home Assistant 令牌以明文保存在 NVS,不回显到网页,但没有加密存储。
- 直连天气使用 TLS,无 PSRAM 时内存紧张;每次进入应用会在串口记录剩余内存与最大块。
- 云端直连语音的上传格式(分块 multipart WAV)与朗读接口参数按接口文档实现,尚未真实调用验证;直连识别要等 HTTPS 握手完成才开麦,每次说话前有一两秒等待。
