# 应用需求：番茄时钟（feature/pomodoro-timer）

## 目标

把设备用作离线番茄时钟：单屏倒计时、三键操作、阶段切换提示音、完成次数统计、
多档息屏与常亮模式。

## 交互与行为

- 默认 25 分钟专注 + 5 分钟休息。
- 主屏 `OK` 单击：开始 / 暂停 / 继续。
- 主屏 `OK` 长按：立即息屏（计时继续，任意键点亮，首键只唤醒不触发功能）。
- READY 时 `上/下` 单击：±1 分钟微调当前阶段时长，范围 1–60 分钟。
- 主屏上键长按：进入设置页（RUNNING 也可进入，但 Focus/Break 时长只读置灰）。
- 主屏下键长按：手动切换图案主题（每完成一个专注段也会自动切换）。
- 设置页五项：Focus、Break、Display、Help、Reset。
  - `上/下` 单击：上下移动选中行（循环五项）。
  - `OK` 单击：修改选中项——时长 +1 分钟循环（非 RUNNING，60 后回到 1）、
    Display 循环下一档、Help 打开按键说明页（说明页 `OK` 返回）、
    Reset 立即重置当前阶段并返回主屏。
  - `OK` 长按：保存并返回主屏。
- Display 档位：30s / 60s / 120s / 5min / 常亮，默认 60s；常亮时不自动息屏，
  手动息屏仍可用。
- 自动息屏后计时继续在后台运行；息屏时第一次按键只点亮屏幕，不触发功能，
  松手（RELEASE）事件不唤醒，避免长按息屏后被松开动作立即点亮。
  此为背光关闭，不是 light/deep sleep；省电路线见
  [pomodoro-power-roadmap.zh_CN.md](pomodoro-power-roadmap.zh_CN.md)。
- 专注结束：完成次数 +1、提示音 3 声、自动进入休息计时。
- 休息结束：提示音 2 声，回到专注 READY，等待手动开始。
- 时长、完成次数、主题、Display 档位写入 NVS（命名空间 `pomodoro`），重启保留。
- 屏幕右上角显示电量；电量计或音频不可用时分别显示 `--`、仅静默切换阶段。

## 界面

自绘界面（不沿用基线测试菜单或像素演示外壳）：其他文字使用 Montserrat 14/20
并禁止换行避免重叠；倒计时使用 5x7 字模整数倍放大的像素数字，运行时冒号闪烁。
阶段图案为字符画双帧动画精灵，RUNNING 时每 400ms 换帧并上下跳 2 像素。
三套主题轮换：果园（番茄 / 咖啡）、猫咪（端坐 / 睡觉）、太空（火箭 / 月亮），
每完成一个专注段自动切换，主屏长按下键也可手动切换，主题写入 NVS。
完成次数用小番茄图标（最多 4 枚）加计数表示；主屏另有进度条、状态行与底部
按键提示；设置页为五行可选中卡片，另有独立按键说明页。界面文本全部为英文。

## 结构

- `main/pomodoro.c/h`：纯逻辑状态机，不依赖 ESP-IDF/LVGL。
- `main/main.c`：UI、输入分发、提示音任务、NVS 持久化、息屏控制。
- `main/pixel_time.c/h`：5x7 字模大号像素倒计时渲染。
- `main/pixel_art.c/h`：字符画像素精灵渲染与三套双帧动画主题。
- `tests/test_pomodoro.c`：状态机主机测试，已注册进 `tools/validate.sh`。
- `docs/development/pomodoro-power-roadmap.zh_CN.md` / `.md`：省电路线规划。

## 验收

- `./tools/validate.sh --all` 通过。
- 真机确认：首屏渲染无重叠、开始/暂停/继续、OK 长按息屏与唤醒、READY 微调时长、
  RUNNING 进设置且时长只读、Display 各档位与常亮、Help 页进出、Reset 执行、
  主题手动/自动切换、到点提示音、完成次数与设置重启保留、电量显示。
